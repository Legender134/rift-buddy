# 开黑搭子 1.0

少翻攻略，专注游戏。

首个正式版围绕从选人到对局的完整体验：自动连接客户端、同步公开阵容和组队状态，将阵容、配置、图鉴与局内参考放在手边。

- 匹配与排位：结合常用英雄偏好、已选阵容及公开对位信息推荐，保留手动位置；队友可提议阵容和投票。
- 海克斯：共享备选池合并头像、胜率与选用标记；推荐阵容显示机制契合分，下方可查看当前版本的全英雄强化胜率榜。串行快速换人、带作者出处的社区方向、图鉴和配置小窗集中展示。
- 配置与战绩：符文、召唤师技能、装备和加点集中展示；本机保留常用英雄摘要，逐局战绩只在当前运行内存中使用。
- 局内参考：双方装备价值、配置、加点与刷野规划按需显示，图标悬停看说明，更多方案可以展开与置顶。
- 换人体验：保留最后一次点击，重新核对本人资格及实际英雄；成功时直接更新头像，失败才提示。备选池为空时保持紧凑，海克斯配置不再出现无关的峡谷应用按钮。

连接、同步、推荐和展示自动跟随游戏；写入配置需要玩家点击，锁定、购买、加点和游戏操作仍由玩家完成。契合分与历史分时统计不代表本局预测胜率。

本文件记录正式版候选。公开安装包、增量补丁与下载入口须在同版发布验收后更新；本版只提供当前公开0.59.33到1.0.0的新增量，不再维护更早的增量与桥接包。
